# ItemVault

Stop accidentally vendoring your important materials. ItemVault is a lightweight Dalamud plugin for Final Fantasy XIV that lets you assign custom tags to items so you can speed-sort your bags without having to mentally keep track of what you're saving and what you're selling. 

## Features
* **Visual Organization:** Adds clean, native-looking tags ([Keep], [Sell], [Keep For Now]) directly to item tooltips, blending in perfectly next to the game's default `quantity` text.
* **Tag From Anywhere:** Bypass standard UI limits. Right-click items to tag them from almost anywhere in the game, including:
  * Your standard bags & Armoury Chest
  * Retainer Inventories & Venture Result windows
  * The Chocobo Saddlebag
  * The Marketboard & Item Search
  * Linked items in the Chat Log
  * Crafting & Gathering Logs

## How to Use
Simply right-click on any item in a supported window and select your tag from the context menu. The tag will instantly appear on the item's tooltip so you always know exactly what to do with it at a glance.

## Installation
To install ItemVault, add this custom repository to Dalamud:

1. Open Dalamud Settings (type `/xlsettings` in chat).
2. Go to the **Experimental** tab.
3. Scroll down to **Custom Plugin Repositories**, and paste this exact link:
   `https://raw.githubusercontent.com/Sebaek98/ItemVault/main/pluginmaster.json`
4. Click the `+` button to add it, and make sure the "Enabled" box is checked.
5. Save and close. You can now search for "ItemVault" in the standard Plugin Installer!
